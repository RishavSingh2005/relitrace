# License decision required before an open-source release

The original ReliTrace dashboard did not contain a `LICENSE` file, so this packaging step does not assign legal license terms on your behalf. A public GitHub repository without an explicit license is visible but not automatically open source.

If you wish to make ReliTrace open source, choose and add a license before announcing release. Common options include **MIT** (permissive) or **Apache-2.0** (permissive with express patent license). Ensure you have rights to license the code and that third-party dependencies and data-use terms are respected.
